# plugin-fanart

High-quality logos, clear art, discs, banners and backgrounds for movies and series from fanart.tv. You enter your own personal API key. An official [Kryspal Media](https://github.com/kryspal) plugin, built on [plugin-sdk](https://github.com/kryspal/plugin-sdk).

```sh
go build -o fanart .
go vet ./... && go test ./...
```

Implementation notes: [docs/design.md](docs/design.md).
